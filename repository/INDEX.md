## 📝 File Naming Convention Guide

### Military Documents
- `dos-uap-dX`: State Department cables (X = document number)
- `dow-uap-dX`: DOD UAP reports (X = report number)
- `65_hs1-*`: Large technical sections from classified report

### NASA Documents
- `nasa-uap-dX`: NASA debriefings
- `nasa-uap-vmX`: NASA video materials

### FBI Documents
- `fbi-photo-aX`: FBI field photographs (PNG)
- `fbi-photo-bX`: FBI photo analysis (PDF)

### Other
- `serial-X`: Serial documentation
- `usper-statement`: User/person statement
- `DOD_*`: DOD video files (MP4)
